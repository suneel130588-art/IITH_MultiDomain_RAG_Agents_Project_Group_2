How it works

Every question goes through the same five agents, in a fixed order, built as a LangGraph StateGraph. Each agent reads the shared state, does one job and writes its result back.

  1. 1
    Router Agentrouter · LLM (structured)

    Classifies the question into a domain, rates severity and emergency, and extracts a named contract and any medicine names.

  2. 2
    Retrieval Agentretrieval · no LLM (one for two-step questions)

    Hybrid search in that domain: MiniLM vectors + BM25 keywords, merged by Reciprocal Rank Fusion (top 8; 12 inside a named contract). Adds finance tables, error-code matches and a second-hop search for two-step questions.

  3. 3
    Domain Check Agentdomain_check · OpenFDA + LLM only when medicines are named

    For health questions, fetches the official medicine labels from OpenFDA and keeps only interaction findings whose quote is really in the label.

  4. 4
    Answer Agentanswer · LLM (free text)

    Writes the answer from the evidence only, following the domain's rules, with a source ID after every fact.

  5. 5
    Safety Agentsafety · LLM audit (1–2×), repair if needed

    Removes citations to sources that were not retrieved, audits every statement against the evidence and OpenFDA labels, removes only statements two audits agree are unsupported, and replaces the answer with emergency advice when needed.
